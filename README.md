# SIDESI - Sistem Informasi Sadar Pelatihan Terintegrasi

**SIDESI** adalah inovasi pelayanan publik milik **UPT Balai Latihan Kerja Pasuruan**, di bawah naungan Dinas Tenaga Kerja dan Transmigrasi Provinsi Jawa Timur. Proyek ini bertujuan untuk memberikan kemudahan bagi masyarakat dalam mengakses informasi pelatihan, mendaftarkan diri secara online, serta mengikuti rangkaian seleksi yang transparan.

## 🚀 Fitur Utama

- **Pendaftaran Pelatihan Terintegrasi**: Mendukung berbagai jenis pelatihan seperti Institusional, MTU, Short Course, dan Swadana.
- **Layanan Pasca-Pelatihan**: Fitur Katalog Alumni untuk wirausaha mandiri dan Bursa Kerja untuk karir di sektor formal.
- **Computer Based Test (CBT)**: Integrasi seleksi ujian berbasis komputer yang transparan.
- **Dashboard Statistik**: Menampilkan data real-time mengenai anggaran, pendaftaran, dan penempatan alumni.
- **Lapor SIDESI**: Sistem pengaduan, Customer Care, dan Whistleblowing System (WBS).

## 🛠️ Teknologi yang Digunakan

- **Frontend**: HTML5, Vanilla CSS, Bootstrap 4.
- **Interaksi**: JavaScript, jQuery, Owl Carousel (Slider), ScrollReveal (Animations).
- **Integrasi**: Google Maps API, Google Looker Studio (Data Statistik).
- **Ikon**: Font Awesome 4.7.0.

## 📂 Struktur Proyek

```text
sidesi/
├── assets/
│   ├── css/        # File stylesheet (Bootstrap, Custom, etc.)
│   ├── images/     # Aset gambar dan logo
│   ├── js/         # File JavaScript (jQuery, Plugins, Custom)
│   └── fonts/      # File font (jika ada)
├── index.html      # Halaman utama aplikasi
└── .htaccess       # Konfigurasi server (Apache)
```

## 💻 Cara Menjalankan

1. Pastikan Anda memiliki web server lokal terinstal (seperti **XAMPP**, **WAMP**, atau **Laragon**).
2. Salin folder proyek ini ke direktori `htdocs` (untuk XAMPP) atau direktori publik server Anda.
3. Jalankan Apache melalui Control Panel web server Anda.
4. Buka browser dan akses `http://localhost/sidesi`.
